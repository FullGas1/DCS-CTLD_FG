CTLD Menu Manager

Complete Technical Specification Reference

API Overview

The MenuManager provides 9 public methods organized into two categories:

  • Singleton Management: getInstance()
  • Group Menu Creation: createMenuForGroup()
  • Menu Item Modification: addSubMenu(), addCommand(), removeMenuBranch()
  • Menu Refresh: refreshMenuForGroup()
  • Menu Retrieval: getMenuByGroupId(), getMenuByGroupName(), getMenuByUnitName(), getMenuByUnitId()

Complete Method Reference

1. MenuManager:getInstance()

Category: Singleton Management

Signature

function MenuManager:getInstance()
    -- Returns: MenuManager instance
end

Description

Returns the singleton MenuManager instance. Creates it on first call.

Parameters

None

Returns

MenuManager singleton instance

Example

local mgr = MenuManager:getInstance()
local menu = mgr:createMenuForGroup(42)

2. MenuManager:createMenuForGroup(groupId)

Category: Menu Creation

Signature

function MenuManager:createMenuForGroup(groupId)
    -- Returns: Menu object or nil
end

Description

Creates an empty menu structure for a group. Must be called before adding items.

Parameters

groupId number Numeric group identifier in DCS Required

Returns

Menu object on success, nil on failure

Errors

- Invalid groupId (nil, non-numeric) - Menu already exists for group

Example

local menu = mgr:createMenuForGroup(42)
if menu then
    menu:addSubMenu({}, "CTLD")
end

3. Menu:addSubMenu(pathTable, menuName)

Category: Menu Item Modification

Signature

function Menu:addSubMenu(pathTable, menuName)
    -- Returns: { success = bool, message = string, subMenuId = string }
end

Description

Adds a submenu at the specified path. Submenus can contain other submenus or commands.

Parameters

pathTable table Path to parent (e.g., {"CTLD"}) or {} for root Required
menuName string Display name for submenu Required

Returns

{
  success = true|false,
  message = "description",
  subMenuId = "sub_123"
}

Errors

- Path not found
- Attempting to add submenu to command
- Invalid menu name

Example

local result = menu:addSubMenu({"CTLD"}, "Troop Transport")
if result.success then
    print("Created: " .. result.subMenuId)
end

4. Menu:addCommand(pathTable, commandName, functionToCall, anyArgument)

Category: Menu Item Modification

Signature

function Menu:addCommand(pathTable, commandName, functionToCall, anyArgument)
    -- Returns: { success = bool, message = string, commandId = string }
end

Description

Adds an executable command at the specified path.

Parameters

pathTable table Path to parent or {} for root Required
commandName string Display name Required
functionToCall function Callback to execute. Signature: function(arg) where arg is your argument table Required
anyArgument table Data to pass to callback (MUST be a table). Passed as-is without modification Optional (default: {})

Returns

{
  success = true|false,
  message = "description",
  commandId = "cmd_456"
}

Errors

- Path not found
- Invalid function reference
- Menu capacity exceeded (1000 items)
- Attempting to add command to command

Example

local function myCallback(arg)
    local squadType = arg.squadType     -- From your argument table
    print("Deploying: " .. squadType)
end

local result = menu:addCommand(
    {"CTLD", "Deploy"},
    "Infantry",
    myCallback,
    { squadType = "squad_1" }
)

if result.success then
    print("Command ID: " .. result.commandId)
end

5. Menu:removeMenuBranch(pathTable)

Category: Menu Item Modification

Signature

function Menu:removeMenuBranch(pathTable)
    -- Returns: { success = bool, message = string, removedCount = number }
end

Description

Recursively removes a menu branch and all its children.

Parameters

pathTable table Path to branch to remove Required

Returns

{
  success = true|false,
  message = "description",
  removedCount = 5
}

Errors

- Path not found
- Cannot remove root menu

Example

local result = menu:removeMenuBranch({"CTLD", "Vehicles"})
if result.success then
    print("Removed " .. result.removedCount .. " items")
    mgr:refreshMenuForGroup(groupId)
end

6. MenuManager:refreshMenuForGroup(groupId)

Category: Menu Refresh

Signature

function MenuManager:refreshMenuForGroup(groupId)
    -- Returns: { success = bool, message = string, refreshedCount = number }
end

Description

Clears entire DCS menu for group and reconstructs from memory. Atomic operation.

Parameters

groupId number Group to refresh Required

Returns

{
  success = true|false,
  message = "description",
  refreshedCount = 15
}

Algorithm

  1. Validate menu exists in memory
  2. Call missionCommands.removeItemForGroup() to clear all items
  3. Traverse menu tree depth-first
  4. For each node: call appropriate DCS API (addSubMenuForGroup or addCommandForGroup)
  5. Handle pagination automatically
  6. Return status

Example

menu:addCommand({}, "New Item", func, { itemId = "item1" })
local result = mgr:refreshMenuForGroup(groupId)
if result.success then
    trigger.action.outText(result.message, 5)
end

Data Structure Schema

Root Menu Node

{
    groupId        = number,        -- DCS group ID
    groupName      = "string",      -- Group name for lookup
    children       = { ... },       -- Array of child nodes
    _lookup        = { ... },       -- Path → node reference mapping
    nextItemId     = number,        -- Counter for unique IDs
    manager        = reference      -- Back-reference to MenuManager
}

Submenu Node

{
    id             = "sub_123",     -- Unique identifier
    name           = "string",      -- Display name
    type           = "submenu",     -- Node type marker
    index          = number,        -- Position in parent's children
    children       = { ... }        -- Child nodes
}

Command Node

{
    id             = "cmd_456",     -- Unique identifier
    name           = "string",      -- Display name
    type           = "command",     -- Node type marker
    index          = number,        -- Position in parent's children
    functionToCall = function,      -- Callback reference
    anyArgument    = any            -- User data for callback
}

Error Codes & Handling Strategy

Error Return Format

All methods that can fail return a table:

{
    success = false,
    message = "Descriptive error message"
}

Common Error Messages

Error Message Cause Solution
"Path not found: ..." Parent path doesn't exist Create parent submenu first
"Invalid groupId" groupId is nil or non-numeric Check group extraction from DCS
"Cannot add submenu to command" Trying to add child to command Use submenu containers instead
"Invalid function reference" functionToCall is not callable Pass function reference, not string
"Menu capacity exceeded" Total items >1000 Reduce menu size or split across groups
"Menu not found for group" No menu created for that groupId Call createMenuForGroup() first

Performance Specifications

Operation Timing

Operation Typical Time Notes
addCommand/addSubMenu <1ms O(1) operation
removeMenuBranch (5 items) <2ms O(n) where n=items in branch
refreshMenuForGroup (15 items) 5-10ms Includes DCS API calls
refreshMenuForGroup (100 items) 35-50ms Acceptable in DCS single-thread
refreshMenuForGroup (1000 items) 200-300ms Not recommended, plan carefully

Limits & Constraints

Limit Value Notes
Max items per submenu Unlimited Paginated if >10 visible items
Max menu depth Unlimited Recommend <5 levels for UX
Max items per menu 1000 Hard limit to prevent memory issues
Max simultaneous menus Unlimited Limited by DCS group count
Refresh frequency 1/sec per menu Recommend <1 refresh/sec to avoid lag

DCS API Constraints & Workarounds

Constraint 1: No Menu Listing API

Issue: Cannot query existing menu items from DCS. Can't validate path before adding.

Workaround: MenuManager maintains complete menu structure in memory. Always validates locally before DCS operations.

Constraint 2: All-or-Nothing Refresh

Issue: Cannot update single menu item. Must clear and rebuild entire menu.

Workaround: Design pattern: accumulate changes, apply via single refresh() call.

Constraint 3: Pagination is Manual

Issue: DCS doesn't auto-paginate. Must manually create "Next Page" menus.

Workaround: MenuManager handles pagination automatically during refresh.

Constraint 4: No Callback Signatures

Issue: Cannot introspect Lua function signatures. Cannot validate callback compatibility.

Workaround: Document expected signature, validate at runtime if needed.

Compatibility & Requirements

Lua Version

Required: Lua 5.1 or compatible

MenuManager uses only Lua 5.1 features. No external dependencies beyond DCS mission command APIs.

DCS Version

Tested: DCS World 2.7+

Should work on any version with missionCommands API support.

DCS APIs Required

  • missionCommands.addCommandForGroup()
  • missionCommands.addSubMenuForGroup()
  • missionCommands.removeItemForGroup()
  • Unit.getByName()
  • Unit.getByID()
  • Group.getByID()
